🔢 Logic Analyzer Statement Calculus

Each expression is parsed into a Boolean formula. We then enumerate all 2n truth assignments of its n variables and evaluate both formulas on every row. Two statements are logically equivalent exactly when their truth-table columns are identical in every row — that is, when A ↔ B is a tautology.

Input syntax

Variables: any letters (p, q, x1…) · NOT: ~ ! not · AND: & and · OR: | or · XOR: ^ xor · IMPLIES: -> implies · IFF: <-> iff · Constants: True False 1 0
Precedence: ~ > & > ^ > | > -> > <->. Use parentheses to be explicit.

🔗 Relation Checker Sets & Relations

A relation R on a set A is a subset of A × A. We test the defining properties directly:

  • Reflexive every a satisfies (a, a) ∈ R
  • Symmetric (a, b) ∈ R ⇒ (b, a) ∈ R
  • Antisymmetric (a, b) ∈ R and (b, a) ∈ R ⇒ a = b
  • Transitive (a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ R

An equivalence relation is reflexive + symmetric + transitive. A partial order (POSET) is reflexive + antisymmetric + transitive.

🕸 Graph Algorithm Visualizer Graph Theory

The edge list becomes an undirected weighted graph. Dijkstra’s algorithm greedily settles the unvisited vertex with the smallest known distance and relaxes its neighbours; it is correct only for non-negative weights. The Minimum Spanning Tree (Kruskal’s algorithm) sorts the edges by weight and adds each one unless it would close a cycle — checked with union-find — producing a tree of minimum total weight that connects every vertex.
